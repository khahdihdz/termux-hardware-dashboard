# Changelog

## 1.1.0 — Android Device Control & Monitoring
- Added a dedicated Termux:API Center with Sensor Lab, one-time location, camera information and Wi-Fi connection details.
- Added opt-in device controls: flashlight, vibration, notification, text-to-speech, brightness and volume.
- Added on-demand low-battery check with optional notification; no background service or scheduled task.
- Added bilingual labels and explicit permission/error guidance.
- Documented privacy boundaries: no SMS/contact access, recording, automatic photography or telemetry.
- Preserved the existing no-root Bash architecture and fallback behavior.

## 1.0.0 — Initial implementation
- Bilingual terminal dashboard and diagnostics.
- Installer, updater with backup, and uninstaller.
- Bilingual GitHub Pages landing site and CI workflows.
