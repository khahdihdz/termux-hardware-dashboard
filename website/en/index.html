Features

CPU & GPU

SoC, core count, per-core frequencies, system load and GPU renderer when exposed by Android.

Memory & storage

Total and available RAM, swap and accessible filesystem capacity.

Battery & display

Charging state, health, temperature, voltage, resolution and display density.

Sensors & network

IIO sensors, optional Termux:API, IP addresses, routes, DNS and interfaces.

Diagnostics

Check commands and hardware access; unavailable values are reported honestly.

Bilingual & responsive

Vietnamese/English interface that adapts to narrow phone terminals.

FAQ

Does it need root? No. Android or the kernel may restrict some metrics. Termux:API is optional.
